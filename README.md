# 🗄️ Banco de Dados

## 📌 Sobre o projeto

Este projeto foi desenvolvido na disciplina de **Banco de Dados**, com o objetivo de aplicar conceitos relacionados à criação, organização e manipulação de dados em um banco de dados.

## 🎯 Objetivos

* Compreender os conceitos de banco de dados.
* Criar e organizar tabelas.
* Definir relacionamentos entre tabelas.
* Utilizar comandos SQL.
* Inserir, consultar, alterar e excluir dados.
* Desenvolver consultas para obter informações do banco.

## 🛠️ Tecnologias utilizadas

* SQL
* Banco de Dados Relacional
* MySQL

## 💻 Funcionalidades

O banco de dados permite:

* Cadastrar informações.
* Consultar registros.
* Atualizar dados.
* Excluir registros.
* Relacionar informações entre diferentes tabelas.
* Realizar consultas utilizando SQL.

## ▶️ Como executar

1. Instale um sistema gerenciador de banco de dados, como o MySQL.
2. Abra o arquivo `banco.sql`.
3. Execute os comandos SQL para criar o banco e suas tabelas.
4. Insira os dados necessários.
5. Execute as consultas para visualizar e manipular os registros.
