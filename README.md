🗄️ Banco de Dados
📌 Sobre o projeto

Este repositório contém atividades realizadas na disciplina de Banco de Dados, com o objetivo de aprender e praticar os conceitos básicos de criação, organização e manipulação de dados utilizando SQL e MySQL.

🎯 Objetivos
Aprender os conceitos básicos de banco de dados.
Criar tabelas e organizar informações.
Inserir, consultar, atualizar e excluir dados.
Entender os relacionamentos entre tabelas.
Praticar comandos SQL por meio de exercícios.
🛠️ Tecnologias utilizadas
SQL
MySQL
MySQL Workbench
📚 Conteúdos estudados
Criação de bancos de dados e tabelas.
Chaves primárias e estrangeiras.
Inserção de dados (INSERT).
Consulta de dados (SELECT).
Atualização de dados (UPDATE).
Exclusão de dados (DELETE).
Filtros (WHERE).
Ordenação (ORDER BY).
Relacionamento entre tabelas (JOIN).
Agrupamento de dados (GROUP BY).

💻 Atividades realizadas

Neste projeto, são desenvolvidos exercícios para praticar os comandos SQL, criar tabelas, inserir informações e realizar consultas. As atividades ajudam a compreender melhor o funcionamento de um banco de dados relacional.

▶️ Como executar
Instale o MySQL ou o MySQL Workbench.
Abra o arquivo banco.sql.
Execute os comandos SQL.
Confira os resultados das consultas realizadas.
